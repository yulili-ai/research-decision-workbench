# 访谈决策工作台（草稿）

这是一份面向 AI 助手的技能草稿：`research-decision-workbench`。它把一次工作限定在**一个待决事项**上，用已有访谈笔记或材料整理判断依据，标出还缺的环节，并给出下一步研究动作。

本仓库目前只准备了发布素材，不是已经完成的 GitHub 上传结果。技能正文仍标为草稿。它不代替上线审批、正式试验或法律审查，也不把一次谈话写成市场结论。

## 它做什么

收到相关请求时，技能会先确认要改变的决策是什么，再写下一条可以被反证的主张。随后按材料情况工作：

- 没有第一手材料时，只拟采集任务，不给出证据结论。
- 已有材料时，逐片段记账，区分「发生过的事件」「当前看法」「未来打算」和「研究者解释」。
- 用户明确要求模拟时，可以做演示，但必须全程标明合成；演示判断只对这份文本有效，不是真实调研证据。

最终输出三块：

1. **决策卡**：待决事项、决策者与时间、当前主张、材料范围、处置结果。
2. **判断账目**：逐条记录出处、角色、种类、转写，以及对主张的支持、削弱或未知；并检查时间顺序、中间步骤和其他可能解释。
3. **下一次最小验证任务**：一个针对性问题，或一个范围有限的小试验。

处置只有三种：继续收集、可做小规模试验、当前不支持。技能不给产品下定论，也不授权任何自动执行或上线。

## 如何使用

在对话里直接说明要使用 `research-decision-workbench`，并给出待决事项；有笔记就一并粘贴，没有笔记也可以先只要采集任务。

也可以手动复制安装：把本目录中的 `SKILL.md` 复制到你所用助手的技能目录，例如项目内的 `.agents/skills/research-decision-workbench/SKILL.md`，或其他助手文档指定的 skills 路径。复制后，用下面这类请求触发。

最小调用例：

```text
用 research-decision-workbench 看这件事：下个迭代要不要开放报销单据的自动核准。还没有访谈笔记。
```

```text
用 research-decision-workbench 处理下面这些笔记，不要补写没出现的情节，输出决策卡、判断账目和下一次最小验证任务：
[粘贴已有笔记]
```

```text
用 research-decision-workbench 做一个明确标注的模拟演示：内容审核要不要扩大自动下架范围。这不是真实访谈。
```

## 关于模拟和测试

技能里的对抗检查例是合成材料，用来说明规则应如何工作。它们**尚未作为测试执行**，也不是真实访谈或实测结果。模拟或演示不能当作实证，不能外推市场，也不能写成已经验证的需求。
